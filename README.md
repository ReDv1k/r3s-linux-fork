# rockchip-linux-for-openwrt This is a unique fork of Rockchip-Linux, patched to use certain components in OpenWrt and build firmware for Rockchip (currently only for the nanopi-r3s rk3566 based on kernel 5.10).
Check the r3s-rk3566-5.10-kernel branch. The important file here is the .config file with attached contents for generating revenue from the launch, which I'm duplicating (.config and .config-target from target/linux/rockchip/).
